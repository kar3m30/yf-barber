# 💈 صالون يوسف فاروق | YF Barber House
### دليل الرفع على GitHub خطوة بخطوة من الجوال أو الكمبيوتر:

1. فك ضغط ملف ZIP على جهازك أو افتح موقع GitHub.
2. أنشئ مستودعاً جديداً (New Repository) وسمّه: `yf-barber`.
3. اضغط على "Upload files" واسحب كافة الملفات المستخرجة من الـ ZIP.
4. اربطه مع Vercel.com بنقرة واحدة لتحصل على موقع سريع مدى الحياة!
