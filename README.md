# يوسف فاروق — YF Online

نسخة Online كاملة من موقع يوسف فاروق: حجز، قاعدة بيانات مشتركة SQLite، بطاقة حجز، QR حقيقي، لوحة حلاق محمية، واستقبال/مسح QR.

## تشغيل محلي
1. ثبّت Node.js 20 أو أحدث.
2. افتح المجلد في Terminal.
3. شغّل `npm install`
4. شغّل `npm start`
5. افتح `http://localhost:3000`

## كلمة مرور لوحة الحلاق
الافتراضية: `1987`
يمكن تغييرها على الاستضافة عبر متغير البيئة `ADMIN_PASSWORD`.

## نشر سريع على Render
- أنشئ Web Service جديد من هذا المجلد/المستودع.
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `ADMIN_PASSWORD=1987`
- يفضل ربط Disk دائم إذا أردت الاحتفاظ بقاعدة SQLite بعد إعادة تشغيل الخدمة، واجعل `DB_PATH` مسار ملف داخل الـ Disk.
- Render يعطي الموقع HTTPS، وهذا مهم لتشغيل كاميرا QR من الهاتف.

## ملاحظات مهمة
- قاعدة البيانات الآن مشتركة بين العملاء والحلاق، بعكس النسخة المحلية السابقة.
- QR يحتوي Token للحجز، والماسح يستعلم عن الحجز من الخادم.
- لا تدخل كلمة المرور إلا عند الضغط على «لوحة تحكم الحلاق».
- فتح الموقع من رابط HTTPS هو الوضع المناسب للكاميرا والـ QR.
