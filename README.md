# يوسف فاروق — مشروع جديد

مشروع حجز مستقل تماماً عن المشروع القديم.

## المطلوب قبل النشر

أنشئ قاعدة Turso جديدة تماماً، ثم ضع في Vercel:

- `TURSO_DATABASE_URL`
- `TURSO_AUTH_TOKEN`
- `ADMIN_USER=admin`
- `ADMIN_PASS=9621`
- `SESSION_SECRET` قيمة عشوائية طويلة

## المزايا

- عربي RTL.
- حلاقان: يوسف فاروق، يوسف الصغير.
- الخدمات والأسعار المطلوبة.
- مواعيد من 12:00 ظهراً حتى 01:00 صباحاً بنصف ساعة.
- الحد الأقصى شخصان لنفس الموعد لنفس الحلاق.
- قاعدة بيانات مشتركة.
- كرت حجز مباشر بعد التأكيد.
- QR يتم توليده داخل الخادم.
- لوحة إدارة منفصلة.
- استدعاء العميل التالي.
- قارئ QR بالكاميرا.
- عرض رقم الهاتف في الإدارة.
- فلترة حسب التاريخ والحلاق.

## دخول الإدارة

اسم المستخدم: `admin`
كلمة المرور: `9621`

يفضل وضعهما أيضاً في Vercel Environment Variables وعدم تغييرهما في الواجهة.

## ملاحظة

المشروع يستخدم Turso/libSQL. لا تستخدم قاعدة البيانات القديمة.
